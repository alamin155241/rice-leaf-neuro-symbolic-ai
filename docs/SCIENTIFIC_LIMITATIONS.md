# Scientific Limitations

- Software integration is not experimental validation and does not establish
  improved accuracy, precision, recall, F1, trustworthiness, or agronomic value.
- Phase 9 comparative evaluation remains required for performance claims.
- The CNN may be uncertain or wrong. Synthetic-image smoke-test labels have no
  diagnostic interpretation.
- Image-only requests lack structured phenotype evidence, so symbolic reasoning
  may abstain.
- Guided observations are subjective user confirmations and are not produced by
  a validated feature extractor.
- Phase 5 held and staging rules are research records. Research-mode matching
  does not make them production-ready or expert validated.
- No supplied Phase 5 management record is treated as validated actionable
  treatment unless its stored metadata explicitly supports that designation.
- Grad-CAM is an attention explanation. Thresholded coverage is not validated
  lesion segmentation, exact disease area, or proof of a phenotype.
- Safety thresholds retained from the prototype are deterministic system policy,
  not learned or expert-validated scientific rules.
- Observation Vocabulary v1 is deliberately incomplete. Its values come from
  existing rule conditions, implemented aliases, or explicitly sourced
  phenotype records; it is not a complete botanical ontology.
- A vocabulary-valid user observation is still subjective and is not evidence
  that a Phase 6 rule matched. Fields without an authoritative enum remain
  unvalidated free text. Staging and production disable that free text unless an
  explicit server policy flag enables it.
- Boolean support and the numeric input type are schema definitions, not
  extracted scientific categories. No numeric lesion-width range is imposed.
- The Phase 7 minimum modality bound is preserved as a raw audit result. A
  separate runtime policy assigns zero effective symbolic weight only when the
  symbolic engine abstains; this policy is not a new scientific coefficient.
- Candidate predictions are retained for audit when deterministic safeguards
  withhold the authoritative diagnosis. A candidate must not be interpreted as
  a final diagnosis.
- Results do not replace assessment by an agronomist or plant pathologist.
